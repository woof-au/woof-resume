# Woof — Resume

A responsive, dependency-free resume website hosted on GitHub Pages.

## Update the resume

Edit `index.html` in this repository and commit to `main`. GitHub Pages automatically publishes the changes. There are no editing controls on the public site.

- Content: edit the HTML under `EXPERIENCE`, the hero, expertise and contact sections.
- Appearance: edit the CSS in the `<style>` block. Colours are defined in `:root`.
- Print: the public Print / save resume button opens the browser's print dialog. Choose Save as PDF for a document copy.

## Hosting

GitHub repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Content notes

Experience is ordered by relevance, with Void, Surge and Steal an Egg Stock Server first. It is not a dated employment history. Membership figures are supplied community sizes, not a total unique audience or claims of growth. Executive offers are listed separately from roles held. Exceed Reality entries describe assuming the Founder role in existing communities. No dates, performance metrics or specific technical stacks have been invented.

No build, package installation, external fonts or hosting subscription is required.
